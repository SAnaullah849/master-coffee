Technical Colophon

This website was built as part of Assignment 1 for the Introduction to Web Technologies course. The primary goal was to demonstrate a deep understanding of HTML semantic structure without the use of styling.

To create a new page in this project, I used the following command in my terminal:

touch index.html

The basic structure of every page follows this pattern:

<!DOCTYPE html>
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

When testing the site, I used the keyboard shortcut Ctrl + R to refresh the browser page.

The browser response for a missing page is typically: 404 Not Found

This site uses several HTML entities to display special characters, such as & (ampersand), © (copyright), ™ (trademark), and   (non-breaking space).


The total word count for each page was maintained between 150 and 250 words to meet assignment constraints.
